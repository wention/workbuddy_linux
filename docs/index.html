命令行安装（始终获取最新版）

Ubuntu / Debian / UOS / deepin / openKylin · x86_64
url=$(curl -fsSL "https://copilot.tencent.com/v2/update?platform=workbuddy-linux-x64-deb" | jq -r '.url')
curl -fL -O "$url"
sha256sum WorkBuddy-linux-x64-deb-*.deb
sudo apt install ./WorkBuddy-linux-x64-deb-*.deb
Fedora / RHEL / openSUSE · x86_64
url=$(curl -fsSL "https://copilot.tencent.com/v2/update?platform=workbuddy-linux-x64-rpm" | jq -r '.url')
curl -fL -O "$url"
sha256sum WorkBuddy-linux-x64-rpm-*.rpm
sudo dnf install ./WorkBuddy-linux-x64-rpm-*.rpm

ARM64 机器把命令中的 x64 换成 arm64。不确定架构时运行 uname -m：输出 x86_64 选 x64，aarch64 选 ARM64。不要硬编码下载链接，构建号每次发版都会变。

说明

  • 上游 JSON 的 sha256hash 字段与文件实测值可能不一致，本页优先展示 Actions 实际下载计算出的 SHA256；安装前请自行 sha256sum 校验。
  • 更新接口是未公开接口，随时可能变动；本页只是官方直链的追踪器，不托管、不修改安装包。
  • supportsFastUpdate: false，应用内更新在 Linux 上会指向官网，升级请重新下载安装包。
  • 龙芯（LoongArch）没有官方包；deepin 商店的版本是社区移植，不在追踪范围内。
